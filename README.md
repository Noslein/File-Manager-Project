# File-Manager-Project
(A simple File Manager for studies v1.0)

A Python script that automatically organizes files
in the Downloads folder according to their extensions.

## Features

- Automatically creates category folders
- Organizes files by extension
- Supports documents, images, videos, audio and compressed files
- Unknown file types are moved to an "Others" folder

## Categories

- Texts
- Images
- Videos
- Audio
- Compressed
- Others

## Requirements

- Python 3.x

## How to use

Run the script with:

```bash
python filemanager.py
